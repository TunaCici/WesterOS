# AGENTS.md

Follow these practical instructions to work on the WesterOS. Read the REAMDE.md
before starting to understand the project.

## Building

The root-level Makefile is how you can build everything. Learn it well.

Run `make kernel` to build the kernel

## Running

Run `make run` to run the kernel under QEMU with QEMU MCP installed

## Debugging

For runtime analysis and debugging, refer using the QEMU MCP tools.
